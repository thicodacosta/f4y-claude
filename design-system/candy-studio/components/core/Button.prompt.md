Primary call-to-action control used across marketing, dashboard, and forms.
```jsx
<Button variant="gradient" size="lg">Get started</Button>
<Button variant="outline" icon={<PlusIcon size={16}/>}>Add item</Button>
```
Variants: primary, gradient (hero CTAs), secondary, outline, ghost, destructive. Sizes: sm/md/lg. Lifts 1px + brightens on hover.
