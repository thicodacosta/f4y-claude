Ao criar artefatos visuais (slides, mocks, prototipos descartáveis, etc), copie os assets e crie arquivos HTML estáticos para o usuário visualizar. Ao trabalhar em código de produção, você pode copiar os assets e ler as regras aqui para se tornar um especialista em design com esta marca.
Se o usuário invocar esta skill sem nenhuma outra orientação, pergunte o que ele quer construir ou projetar, faça algumas perguntas, e atue como um designer especialista que produz artefatos HTML _ou_ código de produção, dependendo da necessidade.
