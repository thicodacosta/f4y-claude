Chaves de API

As chaves ficam salvas apenas neste navegador e só são enviadas aos respectivos serviços. Use chaves dedicadas a esta extensão, com limite de gasto definido no painel de cada serviço.

console.anthropic.com → API Keys. Obrigatória.

console.groq.com → API Keys. Necessária só para gravar; colar transcrição não usa.

Privacidade

  • Na gravação, o áudio fica em memória só até ser transcrito pela Groq, em trechos de 20 segundos, e nunca é salvo.
  • A transcrição é enviada à Anthropic para gerar o registro.
  • O rascunho e o último registro ficam guardados só nesta sessão do navegador e são apagados quando o Chrome é fechado.
  • Nada é salvo em servidores da Find4You.
