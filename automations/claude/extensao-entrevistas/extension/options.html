Chave de API da Anthropic

A extensão usa sua chave para enviar a transcrição ao Claude. A chave fica salva apenas neste navegador e só é enviada para api.anthropic.com.

Gere uma chave em console.anthropic.com → API Keys. Recomendamos uma chave dedicada a esta extensão, com limite de gasto definido no Console.

Privacidade

  • A transcrição é enviada à API da Anthropic apenas quando você clica em "Gerar registro".
  • O rascunho e o último registro ficam guardados só nesta sessão do navegador e são apagados quando o Chrome é fechado.
  • Nada é salvo em servidores da Find4You.
